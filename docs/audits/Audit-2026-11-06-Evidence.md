# Сохранённые свидетельства аудита — 2026-11-06

Это датированные результаты прежнего аудита, а не текущий статус репозитория.
Основной remediation-план и завершённые пробы удалены после переноса требований
в действующих владельцев и тесты. Навигация: [Architecture](../Architecture.md).

## Контекст проверки

Исходный срез: `de9cd9d9c4f501008c210dc017f268807a751b10`, addon 2.0.0,
Interface 30300; штатный набор тогда прошёл 77/77. После шестой очереди были
зафиксированы 92/92, оба проекта typecheck и 156 Lua rule checks. Эти числа
относятся к своим срезам, а не являются сегодняшним критерием приёмки.

Использовались синтетические Lua 5.1/WASM-сценарии. WoW, GitHub CI/release и
реальные SavedVariables пользователя в том аудите не проверялись. Это отсутствие
свидетельства на дату аудита, а не утверждение о сегодняшних настройках CI.
Новых пользовательских результатов проверки в клиенте эти два отчёта не содержали.
