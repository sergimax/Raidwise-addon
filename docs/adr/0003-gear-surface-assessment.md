# Assess surface suitability without optimizing a build

Gear Check identifies obvious PvE gearing problems using observed equipment and
class/spec reference data. Build/encounter simulation, stat-weight optimization,
upgrade ranking and set-bonus trade-offs belong to a separate analysis; treating
this lightweight check as an optimizer would give its grades more certainty than
the inputs support. Published-list S means item-ID membership in a preset union,
not a unique optimum. Lower item level alone is not a gearing error across raids;
ordinary socket-color mismatch is not penalized because the chosen gem's stats
can be worth more than the socket bonus. Set counts remain informational because
choosing between 2pc/4pc depends on the build. Owners/tests and data maintenance
are linked from the [Gear Check task map](../gear-check/Gear-Check-Progress.md).
